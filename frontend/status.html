POST/token

Não verificado

Autentica, devolve o token de acesso e abre a sessão (cookies HttpOnly). Limitado contra força bruta.

Autenticação
não requer
Corpo (form)
username, password
Respostas
200 · { access_token, token_type } · 401 · 422 · 429

Não é verificado automaticamente: exigiria credenciais e contaria como tentativa de login.

POST/refresh

Não verificado

Troca o refresh token (rotação) e emite um novo token de acesso.

Autenticação
cookie HttpOnly + X-CSRF-Token
Respostas
200 · { access_token, token_type } · 401 · 403

Não é verificado aqui: cada chamada troca o refresh token da sessão. O painel o usa quando o token de acesso vence.

POST/logout

Não verificado

Revoga a sessão no servidor: o token de acesso e o refresh token.

Autenticação
Bearer, ou cookie + X-CSRF-Token
Respostas
204 · 403

Não é verificado aqui: encerraria a sessão. Use "Encerrar sessão" no painel.
